# life-radar

A custom OpenClaw skill that turns multi-channel signals into an action-first daily brief:

- Must-do (today)
- Should-do (soon)
- Nice-to-have
- Suggested next actions

## Files

- `SKILL.md`: skill definition and behavior rules

## Usage

Install this skill in your OpenClaw skills directory and invoke with prompts like:

- "给我每日行动清单"
- "扫一下我今天要处理的事"
- "daily action digest"
